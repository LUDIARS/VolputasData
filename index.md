# VolputasData

This public repository is the file authority for Volputas survey definitions and anonymous
examples. Volputas clones it as an independent repository when local survey data is needed.

# Contents

* [Survey definitions](surveys/) - versioned JSON questionnaires.
* [Responses](responses/) - documentation for local-only response storage.
* [Examples](examples/) - synthetic or anonymous public examples.

# Privacy boundary

* Personal answers and experience data remain local and are ignored by Git.
* GitHub access tokens, OAuth tokens, email addresses, and identifiable profile fields must never
  be committed.
* Only synthetic or anonymized examples may be published.
* The [public survey data policy](POLICY.md) applies to every branch.
